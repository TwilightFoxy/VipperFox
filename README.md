# VipperFox

Локальное Windows-приложение для управления Twitch VIP. VipperFox подключается к EventSub, отмечает VIP, которые написали хотя бы одно сообщение за текущую трансляцию, и автоматически выдаёт VIP после официального уведомления Twitch о Watch Streak.

Готовый установщик Windows x64: [VipperFox 0.1.3](https://github.com/TwilightFoxy/vipperfox/releases/download/v0.1.3/VipperFox_0.1.3_x64-setup.exe).

SHA-256: `E2A3BF984DCF9E135CEE61CFDCC2A0B866897AFF69BF747C85BD6B5EE475A395`

Установщик пока не подписан коммерческим сертификатом, поэтому Windows SmartScreen может показать стандартное предупреждение неизвестного издателя.

## Возможности

- автоматическая выдача VIP при Watch Streak от заданного порога;
- учёт сообщений VIP в течение текущей трансляции;
- отчёт о VIP, которые не писали в чат;
- ручное одиночное и массовое снятие VIP с обязательным подтверждением;
- получение и ручное обновление списка VIP, даже когда канал офлайн;
- история действий, системный трей и безопасное хранение токена в Windows;
- отдельные пресеты масштаба интерфейса и размера шрифта.

## Первое подключение

1. Запустите VipperFox и откройте встроенный гайд.
2. В Twitch Token Generator выберите **Custom Scope Token** и создайте токен с правами `channel:manage:vips` и `user:read:chat`.
3. Вставьте Client ID и Access Token. Пароль Twitch приложению не нужен.

Access Token сохраняется в Диспетчере учётных данных Windows. Остальные локальные настройки и история действий хранятся в SQLite в каталоге данных приложения.

Список VIP доступен и обновляется независимо от того, идёт трансляция или канал офлайн. В настройках предусмотрены отдельные пресеты масштаба интерфейса и размера шрифта.

## Важные ограничения Twitch

- Полную историческую серию просмотров Twitch API не отдаёт. VipperFox узнаёт Watch Streak только из официального события `channel.chat.notification`, когда Twitch показывает milestone в чате.
- Сообщения считаются только пока приложение подключено. Если VipperFox запущен после начала стрима или терял соединение, отчёт помечается как неполный.
- Снятие VIP никогда не выполняется автоматически: после стрима пользователь выбирает одного, нескольких или всех зрителей из отчёта и подтверждает действие.

## Безопасность снятия VIP

VipperFox **не снимает VIP автоматически**. Запрос на снятие отправляется только после трёх явных действий пользователя:

1. Выбрать зрителя или группу зрителей в готовом отчёте.
2. Нажать кнопку снятия VIP.
3. Подтвердить действие в отдельном диалоговом окне.

Автоматически приложение может только **выдать** VIP при достижении настроенного Watch Streak.
